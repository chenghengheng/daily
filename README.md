# Daily

Daily 是一款仅在本机保存数据的生活选择 PWA，用低启动成本记录愿望、非必要消费、候选事项和提醒，并在用户主动提供可用时间后推荐一件具体的事。它不是预算或完整账本软件；愿望中的人民币刻度表示“等待进度”，不是余额、存款或可支配金额。

## 运行与安装

项目是无构建的原生 HTML/CSS/JavaScript 应用。不要直接用 `file://` 打开；在仓库目录启动任意静态服务器，例如 `npx serve .`，然后访问终端给出的地址。支持的浏览器可通过菜单“添加到主屏幕/安装应用”安装 PWA。外部字体不可用时会自动使用系统字体。

## 功能

- 愿望按本地自然日增加独立等待进度，可在到期前或到期后记录购买；购买会记录实际价格并形成计划型非必要消费。
- “随手花”只需金额和一次分类选择，提供本月合计、分类汇总与最近记录。
- 候选事项保留“事、书、影、剧、想法”的手动类型选择，由本地规则补充最低有效时间等内部属性。
- 首页按 10、20、45、60、120 分钟或自定义时间推荐一项，支持计时、切换、完成和时长反馈。
- 可在设置中为当前浏览器会话输入 DeepSeek API Key，用模型补充候选事项内部属性；Key 只放在 `sessionStorage`，不进入备份、localStorage 或仓库，模型失败时自动回退本地规则。
- 倒计时区分期待事件和提醒。提醒默认到期删除，也可明确选择保留在“已经历”。
- 学习模块代码和数据仍保留，但默认由 `config.features.studyEnabled` 隐藏。

## 数据、导入导出与隐私

数据保存在当前浏览器的 `localStorage`，没有登录、云端数据库或多设备同步。设置中的完整导出包含配置、愿望、学习、倒计时、候选事项、消费、推荐事件和偏好、计时状态、背景及 schema 版本。导入前会验证结构；旧愿望 `clickLog` 和旧随手记可兼容读取。重要写入会保留最近 10 个轻量快照。清单页面的“清空所有物品”只清空清单；完整数据中的背景图只有通过“移除背景”或完整清理才会删除。

背景图可能显著占用浏览器配额。浏览器清站点数据、隐私模式回收或卸载应用都可能删除数据，请定期导出备份。

## 测试

```sh
npm test
npm run check
```

测试覆盖本地自然日、跨日累计、封顶日志、旧字段迁移、导入结构、本地推断和推荐边界。移动端仍需手工确认触控、系统文件选择器、PWA 安装和离线启动。

## PWA 限制

Service Worker 仅为导航请求提供应用壳离线回退，静态资源失败不会错误返回 HTML。检测到新版时应用会提示刷新。PWA 在完全关闭后不能可靠触发本地通知；当前只保证应用运行期间的到期显示与计时。没有接入 LLM，所有核心功能均可离线运行；未来模型接入必须通过无状态服务端代理，客户端不得保存 API Key。
